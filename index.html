¿Cómo funciona la repetición de fichas?

El sistema utiliza el algoritmo científico Anki SM-2 (Spaced Repetition) para memorización activa a largo plazo:

  • Difícil (Repasar Hoy): Reinicia el intervalo a 1 día. Esta tarjeta se marca para repaso inmediato y la puedes consultar en cualquier momento en el filtro "Fichas por Repasar / Difíciles".
  • Bueno / Regular (6 días): Aumenta progresivamente el intervalo de repaso de forma moderada.
  • Fácil / Dominada (10+ días): Multiplica el intervalo y suma la tarjeta a tu contador de Dominadas.
